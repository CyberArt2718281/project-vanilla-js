# Frontend

## Описание

Этот проект представляет собой клиентскую часть веб-приложения для управления финансами, разработанную с использованием TypeScript и современных веб-технологий. Приложение предоставляет удобный пользовательский интерфейс для управления доходами и расходами с визуализацией данных.

## Основные возможности

- **Управление операциями**: создание, редактирование и удаление доходов и расходов
- **Категоризация**: организация операций по категориям доходов и расходов
- **Визуализация**: интерактивные круговые диаграммы для анализа финансов
- **Фильтрация по периодам**: просмотр данных за день, неделю, месяц, год или произвольный интервал
- **Аутентификация**: безопасная система авторизации пользователей
- **Адаптивный дизайн**: корректное отображение на всех устройствах
- **TypeScript**: строгая типизация для повышения надежности кода

## Функционал

### Страницы приложения

- **Главная** (`/`) - дашборд с диаграммами доходов и расходов
- **Авторизация** (`/login`) - вход в систему
- **Регистрация** (`/sign-up`) - создание нового аккаунта
- **Доходы** (`/income`) - управление категориями доходов
- **Расходы** (`/expenses`) - управление категориями расходов
- **Доходы и расходы** (`/income-expenses`) - управление операциями
- **Создание операции** (`/income-expenses/create`) - добавление новой операции
- **Редактирование операции** (`/income-expenses/edit`) - изменение существующей операции

### Компоненты

- **Аутентификация**: полная система авторизации с JWT токенами
- **Календарные фильтры**: интуитивно понятная фильтрация по датам
- **Интерактивные диаграммы**: визуализация с помощью Chart.js
- **Валидация форм**: комплексная проверка пользовательского ввода
- **Уведомления**: информирование о результатах операций

## Установка

### Предварительные требования

- Node.js 18+ и npm/yarn
- Docker (для контейнеризации)

### Локальная разработка

1. Перейдите в папку проекта:

    ```bash
    cd frontend
    ```

2. Установите зависимости:

    ```bash
    npm install
    # или
    yarn install
    ```

## Сборка и запуск

### Режимы разработки

- **Запуск dev-сервера с hot reload**:

    ```bash
    npm start
    # или
    yarn start
    ```

- **Сборка для продакшена**:

    ```bash
    npm run build:prod
    # или
    yarn run build:prod
    ```

- **Сборка для разработки**:

    ```bash
    npm run build:dev
    # или
    yarn run build:dev
    ```

### Docker контейнер

- **Сборка образа**:

    ```bash
    docker build -t finance-frontend .
    ```

- **Запуск контейнера**:

    ```bash
    docker run -p 8080:80 finance-frontend
    ```

## Используемые технологии

### Основные

- **TypeScript** - строгая типизация для JavaScript
- **Webpack 5** - сборщик модулей с hot reload
- **SCSS** - препроцессор CSS с поддержкой переменных и миксинов
- **Chart.js** - библиотека для создания интерактивных диаграмм

### Инструменты разработки

- **Babel** - транспиляция современного JavaScript
- **ESLint** - линтер для поиска ошибок в коде
- **Prettier** - автоматическое форматирование кода
- **TypeScript** - статическая типизация

### Архитектурные решения

- **Модульная архитектура** - независимые компоненты
- **REST API клиент** - типизированные HTTP запросы
- **JWT аутентификация** - безопасная авторизация
- **Роутинг** - клиентская навигация без перезагрузки страницы
- **Валидация форм** - комплексная проверка пользовательского ввода

## API интеграция

Приложение интегрируется с backend API для:

- **Аутентификация**: `/api/auth/login`, `/api/auth/signup`
- **Операции**: `/api/operations` (CRUD операции)
- **Категории доходов**: `/api/categories/income`
- **Категории расходов**: `/api/categories/expense`
- **Баланс**: `/api/balance`

- **Минификация** - сжатие JS/CSS для продакшена
